# Glossario

| Parola | Cosa vuol dire in Galactic Feed |
|---|---|
| **Fonte** | Un feed che segui: un sito, un feed RSS/Atom o un canale YouTube. Ogni utente ha le sue |
| **Cartella** | Raggruppa le fonti di un utente. Le cartelle «importanti» fanno partire le notifiche |
| **Notiziario** | Tutti gli articoli delle tue fonti, in ordine di arrivo, con preset e filtri. Fino alla 0.12 si chiamava Flusso |
| **Preset** | Un filtro del Notiziario con un nome: tre pronti (Per te, Tutte, Non letti) e quelli che salvi tu |
| **Filtri** | Il pannello del Notiziario dove ogni interesse, cartella, nazione, fonte o il video si nasconde o si tiene da solo |
| **Per te** | Gli articoli che toccano un tuo interesse, scelti dalle parole chiave, dall'AI o da entrambi |
| **Interesse** | Una parola chiave con priorità alta o media, oppure un gruppo di parole acceso come interesse |
| **Gruppo di parole** | Le parole di un argomento (es. Scienza). Si accende come interesse o per silenziare. Quelli «pronti» li prepara l'amministratore per tutti |
| **Parola silenziata** | Gli articoli che la contengono spariscono dal Notiziario, dalle Edizioni e dalle notifiche |
| **Edizione** | Una selezione in stile giornale, composta dal server agli orari scelti. Ognuno può averne più d'una, con regole proprie |
| **Uscita** | Un numero di un'Edizione, composto a un certo orario |
| **Tag** | Etichetta di una fonte (#Tecnologia), proposta in automatico o scelta da te. È un interesse nei Filtri del Notiziario |
| **Nazione** | Il Paese di una fonte, dal dominio e dalla lingua. Serve ai filtri e alle regole delle Edizioni |
| **Doppione** | La stessa notizia da più fonti: diventa una scheda sola |
| **Testo completo** | Il testo intero dell'articolo, dal feed o estratto dalla pagina del sito |
| **Dock** | La barra a pillola in basso su telefono e tablet: Oggi, Notiziario (con le Edizioni), Cerca, Profilo |
| **Profilo** | Nome, avatar, scorciatoie e statistiche di lettura; sul telefono anche le Impostazioni |
| **Salvati** | Gli articoli che tieni: non si cancellano e sono leggibili offline |
| **PWA** | Progressive Web App: l'app che si installa dal browser, senza store |
| **Istanza** | Un server di Galactic Feed, con i suoi utenti e le sue impostazioni |
| **Serie** | Le versioni con lo stesso `MAGGIORE.MINORE` (es. 0.12): l'etichetta dell'immagine che riceve da sola le correzioni |
| **OIDC** | OpenID Connect: entrare con l'account di un altro sistema di login (Authentik, Keycloak…) |
| **Codice di primo avvio** | Sei cifre scritte nel log, che servono solo a creare il primo amministratore |
